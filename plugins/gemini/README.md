# Gemini

Generate and edit images with Nano Banana: product photos, backgrounds and variations. Billed to the Google account of the key.

## How it connects

An API key from Google AI Studio, pasted once in the app. The key stays in the daemon; agents never see it.

## Permissions

An AI Studio API key with billing (image generation has no free tier)

## What agents can do

- Generate images from text
- Edit or combine reference photos

## What agents don't do

- Use the key outside image generation

Anything that changes something on your behalf (sending, publishing, editing, approving) needs your confirmation first.
