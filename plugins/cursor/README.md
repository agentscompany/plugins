# Cursor

Agents hand coding tasks to Cursor's agent with your subscription and review the result.

## How it connects

`cursor-agent`, installed on the workspace computer (PC). Login: Cursor login in your browser.

## Permissions

Your Cursor account

## What agents can do

- Run coding tasks in a repository with cursor-agent and check the diff and tests

Anything that changes something on your behalf (sending, publishing, editing, approving) needs your confirmation first.
