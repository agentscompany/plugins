# GitHub

Agents follow, open and review pull requests and read issues with your account, through gh, GitHub's official CLI.

## How it connects

`gh`, installed on the workspace computer (PC). Login: device code (github.com/login/device).

## Permissions

gh default scopes: repo, read:org, gist

## What agents can do

- List pull requests waiting for your review, read diffs, checks and comments
- Open pull requests
- Comment, approve or request changes (after you confirm)
- List and read issues

## What agents don't do

- Merge, comment or approve without asking you first

Anything that changes something on your behalf (sending, publishing, editing, approving) needs your confirmation first.
