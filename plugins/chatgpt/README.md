# ChatGPT Images

Generate and edit photos with Codex signed in to your ChatGPT account, without an API key.

## How it connects

`codex`, installed on the workspace computer (PC). Login: ChatGPT login in your browser.

## Permissions

Your ChatGPT plan limits (Plus or higher)

## What agents can do

- Generate images ($imagegen)
- Edit reference photos

Anything that changes something on your behalf (sending, publishing, editing, approving) needs your confirmation first.
